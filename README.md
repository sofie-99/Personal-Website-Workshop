# Personal Website Workshop — Part 1

A beginner-friendly React and Vite portfolio starter.

## Run in VS Code

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. In the integrated terminal, run `npm install` and then `npm run dev`.
4. Open the local address Vite prints, usually `http://localhost:5173`.

## Workshop flow

Part 1 (this starter): page sections, React components, props, personalized text, and colors.

Part 2: add a photo, skills/experience, real project links, a resume button, and a dark-mode toggle.

Part 3: choose small upgrades such as animations, a contact form, a favorite-things card, accessibility improvements, or a blog page.

## GitHub setup

Create a new empty Public repository on GitHub. In this folder, run the following, replacing `YOUR-USERNAME`:

`git init`

`git add .`

`git commit -m "Build personal website workshop starter"`

`git branch -M main`

`git remote add origin https://github.com/YOUR-USERNAME/my-personal-website.git`

`git push -u origin main`

## Important files

- `src/App.jsx`: page content and project data
- `src/components/ProjectCard.jsx`: reusable project card
- `src/index.css`: visual styling
